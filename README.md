# JEdrockCabinet

Веб-приложение (личный кабинет) на Node.js с использованием Express, EJS и Discord.js. Проект реализует серверную часть с рендерингом HTML-страниц через шаблоны EJS, авторизацией через Discord, хранением данных в JSON-файле и поддержкой обмена данными в реальном времени через Socket.IO.

## Стек технологий

- Node.js
- Express — веб-сервер и маршрутизация
- EJS — шаблонизатор для страниц личного кабинета
- Discord.js — интеграция с Discord (бот и/или авторизация через Discord)
- Socket.IO — обмен данными в реальном времени между сервером и клиентом
- express-session — управление пользовательскими сессиями
- node-fetch, unirest — выполнение HTTP-запросов к внешним API
- HTTPS — запуск сервера с SSL-сертификатом (сертификаты хранятся в папке `cert`)

## Структура проекта

```
JEdrockCabinet/
├── assets/           статические файлы (стили, скрипты, изображения)
├── cert/             SSL-сертификаты для запуска HTTPS-сервера
├── views/            EJS-шаблоны страниц
├── db.json           файл с данными приложения
├── script.js         основной серверный файл
├── package.json      зависимости и метаданные проекта
├── package-lock.json файл блокировки зависимостей
└── LICENSE           текст лицензии GPL-3.0
```

## Требования

- Node.js версии 16 или выше
- npm

## Установка

1. Склонируйте репозиторий:

```bash
git clone https://github.com/GilazovDEV/JEdrockCabinet.git
cd JEdrockCabinet
```

2. Установите зависимости:

```bash
npm install
```

3. При необходимости настройте параметры проекта (токен Discord-бота, ключи API и прочие переменные конфигурации)

4. Убедитесь, что в папке `cert` присутствуют корректные SSL-сертификаты, если сервер запускается по HTTPS.

## Запуск

```bash
node script.js
```

После запуска сервер будет доступен по адресу, указанному в конфигурации.

## Данные

Файл `db.json` используется как простое хранилище данных приложения. Перед продуктивным использованием рекомендуется рассмотреть переход на полноценную базу данных.
